# Учёт питания (Schautrack)

Инструменты сервера `schautrack` (в picoclaw: `mcp_schautrack_*`).

## Главное правило

**Ты никогда не считаешь калории и БЖУ сам и не берёшь их из памяти.**
Любое число КБЖУ, которое ты показываешь или пишешь в Obsidian, должно прийти из ответа инструмента
(`log_food`, `day_summary`, `period_summary`, `find_food`, `lookup_barcode`).
Если инструмента нет или он вернул ошибку — скажи об этом, а не подставляй свои цифры.

## Пользователь сообщил, что съел

1. Разбери фразу на продукты и количество. Вес бери ровно как сказал пользователь.
   - «150г гречки» → `{"food": "гречка", "grams": 150}`
   - «2 яйца» → `{"food": "яйцо", "pieces": 2}`
   - «стакан молока» → спроси объём в мл, не угадывай.
2. Вызови `log_food(items=[...], meal="Обед")`. Для «вчера» передай `date="yesterday"`.
3. Покажи пользователю поле `table` из ответа как есть.

Если `log_food` вернул ошибку — ничего не записано. Действуй по тексту ошибки:
- **продукт не найден** → попроси КБЖУ на 100 г с этикетки (или штрихкод), затем `add_food`, затем повтори `log_food`;
- **несколько вариантов** → спроси, какой именно, и передай id (`"#12"`);
- **нужен вес / нужны штуки** → спроси недостающее.

Не заменяй незнакомый продукт «похожим» и не записывай через `log_custom_entry` свои оценки.

## Новый продукт

- С этикетки: `add_food(name, per="100g", calories, protein_g, fat_g, carbs_g)` — значения как на упаковке, с дробями.
- Штучный: `per="piece"` и `piece_grams` (вес штуки), если пользователь его знает.
- Готовое блюдо без веса: `per="portion"`.
- По штрихкоду: `lookup_barcode(code)` → покажи значения пользователю → после подтверждения `add_food(per="100g", ...)`.
- Ошибка в продукте: `update_food(food, ...)`.

## Итоги и Obsidian

- За день: `day_summary(date)` → в заметку вставляй `table`, остаток калорий — `calories_left`.
- За неделю: `period_summary(date_from="-6", date_to="today")`.
- Не складывай числа из разных ответов сам — запроси сводку заново.

## Прочее

- Ошибся при записи: `day_summary` → `delete_entry(id)` → `log_food` заново.
- Пользователь сам назвал итоговые КБЖУ блюда (из меню, из приложения ресторана): `log_custom_entry`.
- Вес: `log_weight(weight, body_fat_percent?)`.
